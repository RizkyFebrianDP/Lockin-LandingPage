## How to Update

1. Replace the placeholder files with actual PNG images from your design
2. Ensure images are optimized for web (compressed but high quality)
3. Use consistent dimensions for all mockup images
4. Test the demo section after updating to ensure proper display

## Demo Section Features

Each demo slide includes:
- **Main Image**: The primary mockup showing the feature
- **Side Image**: Decorative floating element (optional)
- **Title**: Feature name
- **Features List**: 3 key benefits/features with descriptions

The demo section supports:
- Touch/swipe navigation on mobile
- Arrow navigation on desktop
- Auto-play with pause on hover
- Keyboard navigation (arrow keys)
- Slide indicators at the bottom
